Opening Explanation & The Core Mental Model

"You edited your assignment, broke something, and wish you could return to yesterday’s working version."

⚡ 7-Stage Git & GitHub Workflow:
1. Edit files ➔ 2. git status / diff ➔ 3. git add (Stage) ➔ 4. git commit ➔ 5. git push origin ➔ 6. Open PR ➔ 7. Merge & git pull

The 3 Pillars of Code History

  • Saving (Ctrl+S): Writes your edits to your laptop's disk. (Pencil draft)
  • Committing (git commit): Creates a permanent, dated checkpoint in your local repository. (Polaroid photo)
  • Pushing (git push): Uploads your checkpoints to the cloud repository on GitHub. (Sharing album with the team)

🚨 Instructor Rescue Kit (Vim & Fixes)

1. Help! Trapped in Vim editor

Ran git commit without -m flag.

1. Press Esc key
2. Type :wq and press Enter (save & exit)
3. Or type :q! and press Enter to abort

2. Accidental git add of wrong file

git restore --staged <file>

3. Push rejected (Conflicting remote README)

git pull --rebase origin main
git push origin main
