## Hands-On Git Workshop Outline
This repository is configured for our live 8-module hands-on workshop:
1. **Opening Explanation (15m):** The 6 core terms, saving vs. committing vs. pushing, and the 7-stage workflow pipeline.
2. **Environment Setup (15m):** Terminal verification (`git --version`) and author configuration (`user.name`, `user.email`).
3. **Create First Repository (25m):** `git init -b main`, inspecting status, staging, and recording initial commits.
4. **Edit, Compare & .gitignore (20m):** `git diff`, staging bundles, and excluding untracked files like `notes.local.txt`.
5. **Publish to GitHub (20m):** Remote setup (`origin`), understanding `-u`, and cloud push.
6. **Branch & Open Pull Request (25m):** `feature/add-project-details`, `project.md`, and peer code review.
7. **Merge & Synchronize (15m):** Merging PR on GitHub and running `git pull origin main` to synchronize.
8. **Independent Challenge & Quiz (15m):** Creating `learning-goals.md` on a new branch and 5-question mastery quiz.
